
# PortfolioSite

My personal portfolio website, built as an interactive desktop-inspired interface.

I wanted to make something a little more memorable than a standard scrolling portfolio, so the site is designed around a retro desktop UI. Different sections of the portfolio open as windows, including my work, case studies, information about me, and contact links.

**Live site:**  
https://fjamal1200.github.io/PortfolioSite/

## Features

- Desktop-inspired portfolio interface
- Separate windows for About, Work, Case Studies, and Contact
- Draggable and interactive UI elements
- Custom taskbar and desktop icons
- Animated background and visual effects
- Responsive layout
- Links to my projects and social profiles

## Built With

- React
- Vite
- Tailwind CSS
- Framer Motion
- React RND
- React Draggable
- Lucide React
- React Icons

## Running Locally

Clone the repository:


git clone https://github.com/FJamal1200/PortfolioSite.git
cd PortfolioSite


Install the dependencies:


npm install


Start the development server:


npm run dev


Vite will provide a local URL where the site can be viewed in your browser.

## Building the Project

Create a production build:


npm run build


Preview the production build locally:


npm run preview


## Why I Built It

This site serves as both my portfolio and a small front-end project of its own.

Instead of treating the portfolio as just a place to list projects, I used it as an opportunity to experiment with React components, interactive windows, animations, and a more unusual interface while still keeping my work easy to access.

I'll continue updating the site as I work on new projects and case studies.
